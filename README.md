# Дуб

Візуальне полотно для коду. Окремий застосунок для Android (Kivy +
Buildozer), не частина [Вужа](https://github.com/lebichnazar19-create/mova) —
але код усередині квадратів пишеться мовою Вужа.

**Завантажити застосунок для Android:**
[останній реліз](https://github.com/lebichnazar19-create/dub/releases/latest) ·
[dub.apk — пряме посилання](https://github.com/lebichnazar19-create/dub/releases/latest/download/dub.apk)

## Стан проєкту (версія 0.1) — перший крок, проба для ока й рук

- Велике блідо-жовте полотно, що гортається пальцем в усі боки.
- Фіолетовий квадрат «програма» посередині — ядро. Тягнеш ядро — гортається полотно.
- Дотик на порожнє місце — з'являється жовтий квадрат «функція» з центром у точці дотику.
- Дотик на жовтий квадрат — відкривається редактор, усередині пишеш код Вужа.
  «← Полотно» або кнопка «Назад» на телефоні повертає на полотно; квадрат
  лишається на місці зі своїм кодом (перший рядок видно на квадраті).
- Жовтий квадрат можна пересунути пальцем.

Поки навмисно нема: ліній між квадратами, зелених коробок, розвилки
«якщо», зумування щипком, збереження між запусками.

## Дотик по всій висоті

У Вужі низ полотна не ловив дотик: під полотном лежав схований рядок вводу
(висота 0), чиї діти перехоплювали дотики. У Дубі корінь застосунку —
`BoxLayout` з одним-єдиним віджетом (або полотно, або редактор), нічого
схованого під полотном нема. Це перевіряють тести `тести/test_дотик_низу.py`:
квадрат ставиться, відкривається й пересувається на кожній висоті від 0
до верху вікна, включно з нижнім пікселем і кутами.

## Будова

- `polotno.py` — модель полотна без Kivy: координати світ ↔ екран,
  дотик/тягнення з порогом, квадрати, код функцій. Усе тестується на комп'ютері.
- `main.py` — Kivy: малює модель на canvas, передає їй дотики, редактор коду.
- `versiya.py` — версія і versionCode.
- `тести/` — pytest; `тести/pidrobka_kivy.py` підміняє Kivy тими самими
  правилами розсилання дотиків, що й справжній.

## Тести й збірка

```
python3 -m pytest тести/ -q
```

- `.github/workflows/testy.yml` — тести на кожен push.
- `.github/workflows/build.yml` — на push у `main`: Buildozer збирає APK,
  кладе в Artifacts (`дуб-APK-<версія>`) і в Release `v<версія>` як `dub.apk`.
